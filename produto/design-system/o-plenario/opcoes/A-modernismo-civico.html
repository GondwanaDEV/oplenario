O que evitamos — de propósito

Recusado (cara de IA / template)

  • Navy #0F172A + azul de SaaS — o "dashboard de governo" genérico.
  • Cream + serif de alto contraste + terracota (o cluster nº1 de IA).
  • Preto + verde-ácido/vermelhão de acento.
  • Gradiente roxo/rosa, fontes default (Inter/Roboto/Lexend).
  • Layout de jornal (fios capilares, colunas densas).

Escolhido (fundado no subject)

  • Petróleo + latão — cor e metal das insígnias institucionais.
  • Hemiciclo como assinatura — a forma real do plenário.
  • Archivo Expanded (letreiro) + Plex Sans/Mono (engenharia + dado).
  • Modernismo brasileiro: estrutura, luz, concreto, sobriedade.
  • Acessibilidade AAA como piso — não como enfeite.
